# Historical executable oracle

This image runs the two preserved x86-64 `prsd`/`prsdd` executables without
modifying them. It uses a pinned Ubuntu 24.04 amd64 base for a sufficiently new
glibc and extracts four obsolete shared-library families into
`/opt/oracle/root`. It carries two `libgfortran.so.3` versions because the
GWDAC executable requires the GCC 4.4 runtime while the arndt64 executable
requires a later symbol version supplied by GCC 6.

The image also runs the preserved `pnpolw` executables. They request the
historical `libgd.so.1` soname but use only five basic GD entry points that are
also exported by the pinned `libgd.so.2`; a compatibility soname link is
provided solely inside the isolated oracle image. The retained pnpol fixture
does not invoke GD image rendering, and its primary `PNPOL.PCT` comparison is
generated by the Fortran plotting path.

Runtime containment:

- `network_mode: none`;
- all Linux capabilities dropped;
- `no-new-privileges`;
- read-only container root filesystem;
- repository and fixture mounts are read-only; and
- only `/oracle-work`, `/tmp`, and the Phase 1 report mount are writable.

File opens are captured by a small `LD_PRELOAD` recorder built from
`bin/file-trace.c`. This replaces `strace`, whose syscall decoding is unreliable
for amd64 executables under Docker Desktop's Apple Silicon emulation.

From `outputs/container-environment`:

```sh
docker compose build oracle
docker compose up -d oracle
docker compose exec oracle verify-oracle
docker compose exec oracle /phase1/scripts/run-historical-go3pr
docker compose exec oracle /phase1/scripts/run-historical-pnpolw
```

Package file identities and source URLs are recorded under `packages/`.
